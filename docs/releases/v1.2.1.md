# Sentinel 1.2.1

**Cette version remplace la 1.2.0.** Elle s'installe par-dessus : vos données sont gardées.

## Corrections

- **Accueil** : le mot « Bonjour » est retiré ; le titre remonte en haut de l'écran.
- **QR code et vérificateur de liens** : « absent des listes de sites dangereux » n'apparaît plus comme une raison de danger. Il s'affiche seulement quand aucun problème n'est trouvé, comme simple information : cela ne garantit pas qu'un site est sûr.
- **Conseils adaptés** : le conseil final d'un QR code suit la menace (application à ne pas installer, code à ne jamais partager sur WhatsApp ou Telegram, numéro à vérifier sur le site officiel, cryptomonnaie).

## Installation

1. **Sur le téléphone**, ouvrez cette page, descendez jusqu'à **Assets** et touchez **sentinel-1.2.1.apk**.
2. Ouvrez le fichier téléchargé et touchez **Installer**.
3. Play Protect peut afficher « Application non reconnue » : c'est normal hors du Play Store. Touchez **Plus d'informations**, puis **Installer quand même**.

## English

# Sentinel 1.2.1

**This version replaces 1.2.0.** It installs over it and keeps your data.

## Fixes

- **Home**: the word "Hello" is gone; the title moves up to the top of the screen.
- **QR code and link checker**: "not on the lists of dangerous sites" is no longer shown as a reason for danger. It only appears when no problem is found, as plain information: it doesn't guarantee a site is safe.
- **Tailored advice**: the final advice for a QR code matches the threat (an app not to install, a code never to share on WhatsApp or Telegram, a number to check on the official website, cryptocurrency).

## Install

1. **On the phone**, open this page, scroll down to **Assets** and tap **sentinel-1.2.1.apk**.
2. Open the downloaded file and tap **Install**.
3. Play Protect may show "Unrecognized app": this is normal outside the Play Store. Tap **More details**, then **Install anyway**.
